# MySQL JOINs Practice Project

## Project Overview

This project demonstrates the use of various SQL JOIN operations using a Student Management Database.

## Database

Student Database

Tables:

- Departments
- Instructors
- Courses
- Students
- Enrollments

## Topics Covered

✔ INNER JOIN

✔ LEFT JOIN

✔ RIGHT JOIN

✔ FULL OUTER JOIN (using UNION)

✔ CROSS JOIN

✔ SELF JOIN

✔ Aggregate JOIN Queries

## Practice Queries

1. Student Name + Course + Marks
2. Course + Instructor + Department
3. Every Course with Instructor
4. Students without Enrollment
5. Instructor with Courses
6. Courses with Zero Students
7. Full Outer Join
8. Cross Join
9. Mentor and Number of Mentees
10. Students who are Mentor and Mentee
11. Department-wise Student Count
12. Average Marks per Course
